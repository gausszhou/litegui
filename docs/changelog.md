# 更新日志

## 1.0.1

测试与交互修复：

- Dragger 键盘/滚轮同步 `value`
- Tabs plus tab 插入修复
- Area merge 修复
- ContextMenu 子菜单引用
- htmlEncode/htmlDecode 兼容 jsdom
- 单元测试 120 个、覆盖率约 72.8%

## 1.0.0

- Inspector/Tree 拆分到 `litegui/experimental`
- HTML 安全默认值、escapeHTML、Table allowHTML
- API 稳定性与弃用策略
- Playwright Chrome/Firefox
- 主包体积下降

## 0.2.0

- 主题 token 与亮/暗主题
- 基础可访问性
- 按组件导出
- VitePress 文档站

## 0.1.0

- 核心组件、core 抽取、构建与测试基线。
