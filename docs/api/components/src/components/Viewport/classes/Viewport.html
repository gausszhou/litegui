Class: Viewport ​

Defined in: components/src/components/Viewport.ts:150

Viewport — 3D scene canvas with orbit / pan / zoom, object picking, transform gizmo and edit-mode overlays. Works on a component-free ViewportObject[] model: meshes render as unit cubes, cameras as triangles and lights as discs. Mount with host.appendChild(viewport.root); call dispose() to release the window listeners and render loop.

BEM: .lg-viewport .lg-viewport__canvas | __info | __muted

Events: select → string | null pointer picked an object (or empty space) status → string transform / interaction hint context-menu → { x, y } right click on the canvas change → void objects were mutated (transform confirmed/cancelled) transform → { kind, phase } transform started / confirmed / cancelled
